# Dashboard Interface

Surface: public/dashboard.html. Mode: Operate.

The property manager reviews tenant maintenance, compares contractor responses and
controls approval. The first screen is a request inbox and adjacent work order.

Use a compact system sans, 26px page title, 12-14px working text, 218px desktop
sidebar and restrained green action colour. Backgrounds are white and light
neutral green-grey; urgency uses amber, confirmation uses green. Queue items use
dividers and selection shading. Avoid decorative charts and unsupported metrics.

Controls use 6px radii, framed tools 8px, buttons have visible focus and press
feedback. Details and message drafts expand on demand. Mobile stacks queue and
detail, with navigation above. Reduced motion removes transitions.

Preserve real state, show failures, restore failed edits, and label contractor
simulation honestly. No page-load animation or unnecessary blocking dialogs.
